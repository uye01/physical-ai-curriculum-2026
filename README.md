## 운영 원칙 요약

1. **깊이보다 흐름** — 논문 한 편의 실험 세부보다, 계보 단위 비교로 연구 흐름과 인사이트를 얻는다.
2. **최신 우선** — 오래된 원리 논문은 발췌·배경 노트로만 다룬다.
3. **문제 먼저, 도구는 필요할 때** — RT 계보로 한계를 확인한 뒤 Diffusion·Flow Matching을 배운다.
4. **Core / Extension / Update 구분** — 새 논문이라는 이유만으로 Core를 늘리지 않는다.
5. 논문 링크와 버전은 **발표 1주 전에 재확인**한다.
