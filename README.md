# Physical AI 스터디 커리큘럼

**📖 커리큘럼 웹페이지 → <https://uye01.github.io/physical-ai-curriculum-2026/>**

로봇이 세계를 어떻게 관측하고, 표현하고, 예측하며, 행동으로 옮기는가 — Vision-Language-Action(VLA), 정책 학습, world model, reasoning, 실시간 제어가 만나는 지점을 **문제 중심·계보 중심**으로 따라가는 스터디 커리큘럼입니다.

- **14 Chapters · 52 Sessions · 논문 100+**
- 세션은 1시간(발표 40분 + 토론 15~20분), 논문 2~3편을 하나의 비교 질문으로 묶어 진행
- core 계보가 아니면 **2025–2026년 논문을 우선** — 목표는 분야의 이해와 흥미, 그리고 다음 연구를 고를 수 있는 인사이트
- 개정 기준일: 2026-11-20
- Contributors: 김한결, 이우준

## 운영 방식 요약

1. 한 세션은 논문 2~3편을 **하나의 비교 질문**으로 묶는다. anchor 논문으로 개념을 세우고 나머지는 차이점 중심으로 다룬다.
2. 모든 발제는 **세 질문**에 답한다 — 이전 접근은 무엇에서 막혔는가, 무엇을 바꿨는가, 그 변경이 새로 만든 한계는 무엇인가.
3. 논문 링크와 버전은 **발표 1주 전에 재확인**한다.
